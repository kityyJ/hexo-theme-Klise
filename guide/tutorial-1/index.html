# 如何将Tello的eSIM转移到新iPhone？最全eSIM激活指南！

如何将Tello的eSIM转移到新iPhone？最全eSIM激活指南！

2026-09-13 干货教程 JIA

正文

点击到My SIM，这边可以选择转换成实体的SIM卡，也可以选择ESIM，重新转移到一个新手机上。

我们这边演示重新转移到新的iPhone上，

转移之前，需要确保我们的手机是可以兼容这个eSIM的，

输入 *#06# 把手机的IMEI输入到这个空白栏里面，检查一下，

显示两个对勾，说明没问题，然后我们来输入一个安全码，如果忘记安全码的话，可以点击 Reset Security PIN 重置一个。

确认码没问题之后，这边看一下注意事项，

  • 一旦点击激活eSIM，之前的手机会没有信号

  • 激活之前，手机要链接Wi-Fi

确认没问题，我们就点击激活，

然后这边会显示pending，

接着就会生成一个新的二维码，我们用新手机扫描，就可以激活了。

付上iPhone的官方说明激活步骤：

一般我们选第一种就行。

如何在您的iPhone设备上激活eSIM 选项1 - 扫描二维码，请按照以下步骤操作：

  • 打开手机的相机并扫描二维码

  • 当出现“检测到蜂窝计划”通知时，点击它

  • 点击屏幕底部的继续

  • 点击添加蜂窝计划

来到手机上，蜂窝网络，添加eSIM

一步一步直到设置完成，

这边如果一直激活不了，建议打开梯子再尝试激活，

打开Wi-Fi 通话，

搞定了，可以显示Wi-Fi Calling
