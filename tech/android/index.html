scrcpy 安卓投屏实操：USB 连接、降低卡顿与录屏的排查顺序

2026-10-15 科技数码 JIA
版本与设备

依据 scrcpy v5.0.1 官方 README 整理，核对日期 2026-10-15。基本投屏要求 Android 5.0 以上，音频转发要求 Android 11 以上；具体设备仍可能受厂商权限限制。

scrcpy 可以让 Windows、macOS 或 Linux 电脑通过 USB 或网络显示并控制安卓设备。项目采用 Apache-2.0 许可证，不要求 root。首次尝试建议先用数据线把基础连接跑通，再考虑无线连接。

从官方渠道安装

项目明确提醒，GitHub 上的 Genymobile/scrcpy 仓库是其官方来源。按 README 中对应系统的安装说明或官方 Releases 下载，不要因为下载站域名带有 scrcpy 就默认可信。留意系统、处理器架构与发布包是否对应。

准备一根能传数据的 USB 线，而不是只能充电的线。手机打开开发者选项与 USB 调试，连接后在手机上核对授权提示，确认授权的是自己的电脑。

第一次连接先不加复杂参数

在已安装 Android platform-tools 的终端运行：

adb devices 中如果显示 unauthorized，先解锁手机并完成本机授权；如果没有设备，先换线、USB 端口并检查系统驱动。ADB 本身还没连接时，继续修改视频编码参数通常不会解决问题。

成功打开窗口后，先用鼠标完成返回、主页和文字输入，确认画面和控制都正常。电脑较多时不要随意接受陌生调试授权，使用完可在手机设置中关闭 USB 调试或撤销不再信任的电脑授权。

没有声音、只能看不能控制

某些厂商设备还需要单独的 USB 调试安全设置才能注入键鼠输入。官方特别举到部分小米设备的额外开关与重启要求；应按自己设备的官方设置核实，而不是照着陌生教程关闭所有安全功能。

录屏前做一个小样本

需要录制时，可先查看 scrcpy --help 的 Recording 选项，再用短片段检查画面、声音和文件能否播放。录制前关闭会显示个人消息的通知，避免把验证码或聊天内容一起录进去。

先确认基本连接，再分别处理画质、音频和录制，比把一大串参数一次粘进去更容易判断原因。
