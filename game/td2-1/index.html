《全境封锁2》国服官宣停运：12月14日关服，玩家补偿方案完整解读

2026-10-20 游戏 JIA
事件状态

已官宣，即将停运。 2026年10月12日，腾讯运营团队宣布中国大陆国服将于12月14日关闭。这不等于育碧国际服停运。以下时间为北京时间。

《全境封锁2》国服于2023年11月正式上线。运营团队称因业务发展策略变更，经与开发商友好协商决定停止运营。距离正式关服仍有一段时间，已经充值或拥有角色的玩家应该抓紧核对自己的权益。

停服时间表

时间（北京时间） 安排
10月12日11:00 停止充值和新账号注册
10月14日—12月14日 按公告参与停运补偿
12月14日11:00 关闭国服游戏服务器和游戏官网，无法登录
12月22日11:00 关闭官方论坛与专属客服

运营团队同时表示，服务器关闭后，除法律法规另有规定或协议另有约定，将按相关规则处理账号资料与角色数据。建议提前保留充值记录和必要的账号信息。

游戏里的高级点数怎么补偿？

官方公布的补偿不是原路现金退款，而是用其他腾讯游戏的礼包等权益替换符合条件的付费余额、未失效订阅服务。补偿涵盖《和平精英》《金铲铲之战》《无畏契约》《穿越火线》《王者荣耀》等。

适用条件主要为：2026年10月12日11点前充值，且国服账号还有付费获得的未消耗高级点数。 免费赠送的点数不计入。未失效的付费周卡、月卡按照公告约定的剩余时间折算。

符合补偿的高级点数余额 对应礼包档位
0 < 余额 ≤ 1,000 价值10元礼包
1,000 < 余额 ≤ 10,000 价值100元礼包
10,000 < 余额 ≤ 50,000 价值500元礼包
余额 > 50,000 按余额除以50,000后向上取整计算500元礼包份数

请注意表中所谓“价值”是礼包标示价值，不能理解成可直接兑换现金。参与补偿可能意味着接受替换方案；以官方补偿页面最新条款为准。

国际服、Steam版也会关吗？

此次公告仅指腾讯代理的中国大陆国服。育碧旗下的海外运营版本是不同服务体系，不能把国服关停扩大表述为整个《全境封锁2》停止运营。Steam国际版与腾讯国服的账号、角色、道具能否继承或互转，也不能在没有正式声明时擅自保证。

玩家目前应该做的四件事

  1. 判断账号属于腾讯国服还是育碧国际服，确认自己是否受到本次公告影响。
  2. 核对付费高级点数、月卡周卡期限、订单、充值凭证。
  3. 在12月14日前查看官方补偿规则，并在客服关闭前处理异议。
  4. 警惕冒充客服的所谓“国服退款绿色通道”，不要向非官方链接输入密码或验证码。

报道与公告整理来源： IT之家（10月12日）、新京报（10月12日）、游民星空转载运营公告（10月13日）。
