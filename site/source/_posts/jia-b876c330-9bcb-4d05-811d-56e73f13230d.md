::: note 资料与版本
依据 Valve 官方 Proton README 与 proton-11.0-2 发布记录整理，核对日期 2026-10-15。该版本记录发布于 2026-08-21；本文是兼容性排查教程，不是今日补丁快讯。
:::

Proton 是 Steam Play 使用的兼容工具，借助 Wine 等组件让部分 Windows 游戏在 Linux 上运行。Valve 建议普通用户使用 Steam 客户端提供的 Proton；直接编译源码或叠加很多第三方修补，不应成为首次排查的默认步骤。

## 先分清自己遇到哪类问题
记录游戏名称、发行版、显卡和驱动、Steam 客户端以及当前 Proton 版本。现象也要具体：完全没有窗口、启动器能打开但游戏退出、进入后黑屏，还是能运行但特定场景崩溃。

核对游戏的官方平台支持与反作弊要求。兼容工具不能保证所有在线游戏都能运行；服务端或反作弊未开放的支持，不能靠换一个版本就宣称已经绕过。

## 第一步：建立一个不乱改的基线
更新 Steam 客户端，确认发行版的图形驱动与游戏最低需求匹配；通过 Steam 检查游戏文件。保留原来的启动参数和设置截图，先移除自己加过、却不知道作用的非必要参数，再试一次。

先确认本地存档与云同步状态。不要为了“重新来过”直接删除 `compatdata` 或整个游戏兼容目录，其中可能存在本地存档和配置。

## 第二步：只为单个游戏测试版本
在该游戏的属性中查找兼容性选项，必要时选择 Steam 提供的特定 Steam Play 兼容工具。可以在一个稳定版本和 Proton Experimental 之间做有记录的比较；不要一次给整个游戏库改版本。

每次只改一个条件，使用相同存档或同一场景复测。能进主菜单、能读存档、能进入实际场景是三个不同检查点，不能只看到启动器出现就宣布问题已经解决。

## 第三步：让 Proton 输出日志
官方 README 支持在游戏的启动选项中设置环境变量，并保留 `%command%`：

```text
PROTON_LOG=1 %command%
```

复现一次问题后，默认可在用户主目录寻找 `steam-游戏APPID.log`；也可以按官方说明使用 `PROTON_LOG_DIR` 指定日志目录。先核对日志时间是否对应刚才这次启动，而不是拿旧文件判断。

对外提交报告前，检查日志是否包含用户名、路径或其他个人信息，只提供必要片段。问题解决后移除日志选项，避免长期生成不再需要的大日志。

## 第四步：把结果写成可复现的记录
至少写清楚原版本、测试版本、唯一改动、重现步骤和结果。若相同条件下只在某一版本失败，再查看该版本的官方发布说明与相关 issue；不要把一次网络故障误判成所有 Proton 版本都不可用。

::: tip 回退要简单
恢复原兼容工具与启动参数后重新测试。先保留存档与日志，再考虑进一步处理；不靠删除数据制造一次“干净启动”。
:::
