# 小时候写下的理想，后来还记得吗

有时候，真正让人难过的，不是什么轰轰烈烈的事情。

只是一张旧纸，一行歪歪扭扭的字，就能突然把人拉回很多年前。

小时候写下的理想
<img src="/uploads/1788784921125-img-6946-azcdc0rn.jpeg" alt="1788784921125-img-6946-azcdc0rn" width="162" height="215" style="width:162px;height:215px">
照片里的纸上，写着关于小时候的理想。

那时候的字并不好看，想法也很简单。

可现在重新看到，却突然觉得——

**那可能是我们最认真相信未来的时候。**

---

## 我的理想

小时候老师总喜欢问：

> **“你长大以后想做什么？”**

那时候好像每个人都能很快回答。

科学家、宇航员、医生、老师、警察……

不会考虑工资，也不会考虑现实。

更不会去想，这个梦想到底有多难。

| 小时候想的 | 长大以后想的 |
| --- | --- |
| 我以后要做什么？ | 我以后该怎么办？ |
| 我喜欢什么？ | 什么更现实？ |
| 长大一定很好玩 | 原来长大也很累 |
| 时间还有很多 | 时间怎么过得这么快 |
| 我一定可以做到 | 我真的还能做到吗？ |

小时候觉得，

只要自己喜欢，

未来就一定会变成那个样子。

---

{% note warning 后来 %}
小时候最期待的事情，是长大。

后来才发现，

**小时候反而成了最想回去，却永远回不去的地方。**
{% endnote %}

---

## 后来，我们真的长大了

小时候总觉得“长大”是一件很遥远的事情。

总想着：

等我长大了，就可以不用写作业。

等我长大了，就可以买自己喜欢的东西。

等我长大了，就可以去想去的地方。

等我长大了，就自由了。

可是真的走到小时候口中的“以后”，才发现事情并没有那么简单。

| 那时候 | 现在 |
| --- | --- |
| 期待长大 | 怀念小时候 |
| 放学就是快乐 | 下班只是一天结束 |
| 几块钱零食就很满足 | 买了很多东西也未必开心 |
| 暑假好像永远过不完 | 一年转眼就过去了 |
| 总觉得未来很远 | 回头才发现过去已经很远 |
| 对世界充满好奇 | 开始习惯很多事情 |

电脑越来越好。

手机越来越贵。

懂的事情越来越多。

拥有的东西，也比小时候多了很多。

可奇怪的是，

**小时候那种很容易开心的感觉，却越来越少了。**

---

## “我以后一定可以吧”

小时候写下一句梦想的时候，

我们大概真的相信自己能够做到。

不会觉得自己普通。

不会觉得梦想太远。

也不会提前替未来找理由。

那时候最大的担心可能只是：

> **“我以后真的可以成为这样的人吗？”**

现在再看，会觉得有一点幼稚。

但又很羡慕。

因为那个时候的我们，

至少还敢认真地相信未来。

---

{% note info 有些东西变了 %}
长大并不是突然发生的。

它更像是一点一点把小时候的东西拿走。

先是不再期待放学。

然后是不再期待暑假。

再后来，

连生日好像也只是普通的一天。
{% endnote %}

---

## 小时候的世界其实很小

小时候的世界没有现在这么大。

却好像比现在有意思得多。

| 一件很小的事情 | 当时的感觉 |
| --- | --- |
| 买到喜欢的零食 | 可以开心很久 |
| 老师提前下课 | 像中了大奖 |
| 放学和朋友一起回家 | 一天最期待的时候 |
| 考试多拿几分 | 想赶紧回家告诉家里 |
| 暑假第一天 | 感觉未来还有无限时间 |
| 得到一个新玩具 | 能反复玩很久 |
| 周末不用上学 | 前一天晚上都会特别开心 |

现在回头看，

那些事情真的很小。

但当时的快乐是真的。

小时候并不是没有烦恼。

只是那时候的烦恼，

往往睡一觉以后，

第二天就没那么重要了。

---

## 时间到底去了哪里

小时候总嫌一天太长。

一节课四十分钟都觉得很慢。

暑假更像是一段永远不会结束的时间。

后来才发现，

时间其实一直都走得很快。

| 年纪越来越大 | 感觉却越来越明显 |
| --- | --- |
| 一天 | 很快 |
| 一个月 | 没什么感觉就结束 |
| 一年 | 好像才刚开始 |
| 几年前 | 仿佛就在昨天 |
| 小时候 | 明明很远，却又记得很清楚 |

也许不是小时候的时间比较慢。

只是小时候的一天里，

有太多值得期待的事情。

而现在，

日子开始变得相似。

所以时间才像被谁偷偷按下了快进键。

---

> **小时候写的是“我的理想”。  
> 长大以后想的，却慢慢变成了“生活怎么办”。**

---

## 如果真的可以回去一次

如果真的可以回到小时候，

我大概不会告诉那个时候的自己未来发生了什么。

不会告诉他，

小时候的梦想有没有实现。

不会告诉他，

以后会遇到什么人，又会失去什么人。

我只是想在旁边坐一会儿。

看看那个还没有被现实磨掉棱角，

还会为了很小的事情开心，

还认真相信自己以后一定会变得很厉害的小孩。

然后告诉他：

**别那么着急长大。**

作业写不完也没关系。

考试没考好也没关系。

想玩的东西就多玩一会儿。

想见的人就多待一会儿。

因为现在觉得普通的一天，

以后可能会变成一个再也回不去的下午。

---

{% note success 如果可以告诉小时候的自己 %}
慢一点长大。

不要总想着以后。

你现在觉得很普通的生活，

有一天，

可能会成为你最怀念的日子。
{% endnote %}

---

## 后来才明白

我们最终可能没有成为小时候想成为的那个人。

但那并不代表小时候的梦想没有意义。

至少曾经有一个小小的自己，

认真地相信过未来。

| 小时候拥有的 | 后来才知道有多珍贵 |
| --- | --- |
| 天真 | 不会提前怀疑结果 |
| 勇气 | 敢说出很大的梦想 |
| 好奇心 | 什么东西都想知道 |
| 简单的快乐 | 很小的事情也会满足 |
| 对未来的期待 | 总相信明天会更好 |
| 很多时间 | 当时却从来没有珍惜 |

我们怀念的，

或许从来不只是小时候。

而是小时候的那个自己。

---

## 写在最后

{% note primary 关于那张纸 %}
多年以后再看到小时候写过的字，

真正让人难过的，

不是梦想最后有没有实现。

而是突然发现：

**那个认真写下梦想的小孩，已经离自己很远了。**
{% endnote %}

> **后来才明白，最珍贵的从来不是那个梦想有没有实现，而是当年那个真的相信自己什么都能做到的小孩。**

如果有一天还能再见到他，

我想告诉他：

**你不用急着长大。**

因为我已经替你走到了这里。

只是偶尔，

真的很想你。
